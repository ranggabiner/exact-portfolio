# exact-portfolio

Kumpulan app yang saya buat dengan [Exact](https://github.com/expo/exact). Setiap app ada di `apps/`, dan stack-nya tertulis di nama foldernya.

| App | Stack | Status |
|---|---|---|
| [todolist-rust](apps/todolist-rust) | Rust (data), Contract (view) | Masih template awal, fitur todo belum dibuat |

Menjalankan satu app:

```sh
cd apps/todolist-rust
bun exact.mjs --help
bun exact.mjs verify
```
